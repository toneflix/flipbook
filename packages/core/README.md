# @toneflix/flipbook-core

The framework-free heart of Toneflix Flipbook: peel-and-fold page geometry, the spring engine that drops a released page, the book's leaves and labels, and the reader that turns pointer moves into page turns.

You only need this package directly to build a flipbook for another renderer. For React use `@toneflix/flipbook-react`; for React Native use `@toneflix/flipbook-native`.

See the [documentation](https://toneflix.github.io/flipbook/) for the full guide.
